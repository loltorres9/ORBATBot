🛰️ Load a terrain from OCAP background and Arma corners in one go

OCAP already renders every terrain you play on. Paste the address of one of its map folders — the one holding map.json and the numbered tile folders, e.g. https://ocap.your-unit.net/images/maps/tanoa — and this map takes that terrain as its background and its Arma coordinates, so the export lands in the right place without you typing a single number.

The tiles are loaded by whoever opens the map, so the OCAP server has to be reachable for them too. Detail is set under Map settings; one step deeper is four times as many tiles.

📣 Post in a channel as a link, so it stays current

A picture would be out of date the moment the plan changes, so what goes into the channel is a link. The share link is used when there is one; otherwise the link only opens for people who can sign in here.

🎯 Put it into Arma 3 markers in a running mission, no mod

Arma cannot fetch anything from outside without a mod, so the way in is the debug console: paste this and press GLOBAL EXEC as a logged-in admin (#login, and enableDebugConsole in the mission's description.ext). The markers are created globally, so every player sees them. Running it again replaces these markers instead of adding a second copy.

It is built from the saved map, so save first. Where the markers land comes from Arma 3 coordinates in the map settings — set the terrain there before the first export, or everything ends up on Altis. Lines and areas need Arma 2.00 or newer.
