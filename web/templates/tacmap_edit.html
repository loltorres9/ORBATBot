🛰️ Load a terrain from OCAP without uploading it

OCAP already renders every terrain you play on. Point this at the folder it keeps them in and pick one from the list: the map takes that terrain as its background and its Arma coordinates, so the export lands in the right place without you typing a single number.

The tiles are loaded by whoever opens the map, so the OCAP server has to be reachable for them too. Detail is set under Map settings; one step deeper is four times as many tiles.

🎯 Put it into Arma 3 markers in a running mission, no mod

Arma cannot fetch anything from outside without a mod, so the way in is the debug console: paste this and press GLOBAL EXEC as a logged-in admin (#login, and enableDebugConsole in the mission's description.ext). The markers are created globally, so every player sees them. Running it again replaces these markers instead of adding a second copy.

It is built from the saved map, so save first. Where the markers land comes from Arma 3 coordinates in the map settings — set the terrain there before the first export, or everything ends up on Altis. Lines and areas need Arma 2.00 or newer.

Let people move and delete them in game

A marker a script creates is read-only on Arma's map. The engine only lets somebody pick up or delete a marker whose name starts with _USER_DEFINED — that is how it tells one somebody placed from one the mission drew. This version puts that in front of the name, so a marker can be clicked and deleted with DEL or dragged, and pasting a corrected plan still replaces exactly this map's markers. Lines and areas are polyline markers and may well stay fixed; the symbols and objective markers are the part this is for.

It cuts both ways — the same click that fixes a misplaced objective deletes it, and nothing asks first. Run this one with LOCAL EXEC, once: the markers are global either way, and GLOBAL EXEC would draw one set per machine, because the name carries the owner of whoever ran it.
